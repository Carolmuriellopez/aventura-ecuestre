# 🐴 Aventura Ecuestre

Corporate website for **Aventura Ecuestre**, an equestrian excursions company based in Tarifa, Cádiz (Spain). Built with Django and Tailwind CSS v4.

## 🛠 Stack

- **Backend:** Django
- **Frontend:** Tailwind CSS v4, Cormorant Garamond + Jost (Google Fonts), Swiper (carousels)
- **Database:** SQLite (development) / PostgreSQL (production)
- **Server:** Gunicorn + Nginx
- **Hosting:** DigitalOcean
- **SSL:** Let's Encrypt (Certbot)


---

## ✅ Prerequisites

- Python 3.10+
- Node.js and npm
- Git

## 💻 Local setup

### 1. Clone the repository

```bash
git clone git@github.com:YOUR_USERNAME/aventura-ecuestre.git
cd aventura-ecuestre
```

### 2. Create and activate virtual environment

```bash
python3 -m venv env
source env/bin/activate
```

### 3. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 4. Install Node dependencies and compile CSS

```bash
npm install
npm run build
```

### 5. Environment variables

Create a `.env` file in the project root:

```
SECRET_KEY=your_secret_key
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
EMAIL_HOST_USER=your@email.com
EMAIL_HOST_PASSWORD=your_password
```

### 6. Migrate and run

```bash
python manage.py migrate
python manage.py runserver
```

## 🚀 Production deployment (DigitalOcean)

### 1. Clone the repository on the server

```bash
cd /home
git clone git@github.com:YOUR_USERNAME/aventura-ecuestre.git
cd aventura-ecuestre
```

### 2. Create virtual environment and install dependencies

```bash
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
```

### 3. Environment variables

Create the `.env` file in the project root:

```
SECRET_KEY=your_secret_key
DEBUG=False
ALLOWED_HOSTS=aventuraecuestre.com,www.aventuraecuestre.com
EMAIL_HOST_USER=your@email.com
EMAIL_HOST_PASSWORD=your_password
```

### 4. Collect static files and migrate

```bash
python manage.py collectstatic --noinput
python manage.py migrate
```

### 5. Gunicorn service (systemd)

Create `/etc/systemd/system/aventura_ecuestre.service`:

```ini
[Unit]
Description=Gunicorn for Aventura Ecuestre
After=network.target

[Service]
User=root
Group=www-data
WorkingDirectory=/home/aventura-ecuestre
ExecStart=/home/aventura-ecuestre/env/bin/gunicorn \
    --workers 3 \
    --bind unix:/run/aventura-ecuestre.sock \
    aventura_ecuestre.wsgi:application

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl start aventura_ecuestre
systemctl enable aventura_ecuestre
```

### 6. Nginx

Create `/etc/nginx/sites-enabled/aventuraecuestre.com.conf`:

```nginx
server {
    listen 80;
    server_name aventuraecuestre.com www.aventuraecuestre.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name aventuraecuestre.com www.aventuraecuestre.com;

    ssl_certificate /etc/letsencrypt/live/aventuraecuestre.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/aventuraecuestre.com/privkey.pem;

    location = /favicon.ico { access_log off; log_not_found off; }

    location /static/ {
        alias /home/aventura-ecuestre/staticfiles/;
    }

    location / {
        include proxy_params;
        proxy_pass http://unix:/run/aventura-ecuestre.sock;
    }
}
```

```bash
nginx -t
systemctl reload nginx
```

### 7. SSL with Let's Encrypt

```bash
certbot --nginx -d aventuraecuestre.com -d www.aventuraecuestre.com
```

## 📁 Project structure

```
aventura-ecuestre/
├── aventura_ecuestre/      # Django config (settings, urls, wsgi)
├── main/                   # Main app
│   ├── static/main/css/    # Source CSS (input.css) and compiled (output.css)
│   ├── templates/          # HTML templates
│   └── views.py
├── staticfiles/            # Collected static files (generated by collectstatic)
├── env/                    # Virtual environment (not versioned)
├── .env                    # Environment variables (not versioned)
├── requirements.txt
└── manage.py
```
